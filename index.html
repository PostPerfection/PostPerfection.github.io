Getting Started

Prerequisites

  • Rust 1.80+ (for dcpdoctor, postkit, imfwizard, asdcplib-rs)
  • Optional: Node.js 24 and pnpm 11 (for Tauri GUIs)

Building dcpdoctor

git clone --recursive https://github.com/PostPerfection/dcpdoctor.git
cd dcpdoctor/rust
cargo build --release
./target/release/dcpdoctor --help

Building dcpwizard

git clone --recursive https://github.com/PostPerfection/dcpwizard.git
cd dcpwizard/rust
cargo build --release
./target/release/dcpwizard --help

Building imfwizard

git clone --recursive https://github.com/PostPerfection/imfwizard.git
cd imfwizard/rust
cargo build --release
./target/release/imfwizard --help

Using postkit as a library

# In your Cargo.toml
[dependencies]
postkit = { git = "https://github.com/PostPerfection/postkit.git" }

Code Quality

  • Rust: cargo fmt --all && cargo clippy --all-targets --all-features -- -D warnings
  • Frontend: cd gui && pnpm install --frozen-lockfile && pnpm build

DCP Standards Reference

  • SMPTE ST 429, D-Cinema Packaging
  • SMPTE ST 2067, Interoperable Master Format
  • SMPTE ST 378 / ST 379, MXF container
  • SMPTE ST 422, JPEG 2000 for D-Cinema
  • ISDCF, Inter-Society Digital Cinema Forum naming

CI/CD

All repositories use GitHub Actions for continuous integration:

  • Cross-platform builds (Linux, macOS, Windows where applicable)
  • Automated testing on every push and PR
  • Supply chain security via cargo-deny (Rust repos)
